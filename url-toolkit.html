Frequently asked questions

What are UTM parameters?

UTM parameters are tags added to a destination URL so analytics tools can identify the source, medium and campaign associated with incoming traffic.

Does URL cleaning remove every tracking parameter?

The cleaner removes common advertising and click-tracking parameters. Review the result because some websites use query parameters for legitimate functions.

Is URL validation the same as a security scan?

No. It checks URL syntax and basic protocol details. It does not visit the website or guarantee that a destination is safe.

Can this page create Bitly-style short links?

Not yet. Genuine short links require a redirect backend. That capability is planned separately so it can be implemented reliably rather than simulated in a static page.
