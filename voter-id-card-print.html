VOTER ID

About Voter ID printing

The Election Commission of India provides e-EPIC as an electronic version of the Electors Photo Identity Card. InfoJano is an independent print-preparation tool and is not an Election Commission service.

How to prepare your Voter ID for printing

  1. Download your e-EPIC from the official Voters' Services Portal. Keep the original PDF unchanged.
  2. Open InfoJano ID Card Print Studio and choose Voter ID.
  3. Upload the PDF or a clear image. The Voter ID workflow uses manual cropping, so select the complete front card and then the genuine back side if available.
  4. Include the complete coloured border, printed text, photograph and QR code. Review the front and back previews carefully.
  5. The current Voter ID output is fitted to 85 × 55 mm at 300 DPI. Check the paper layout preview and export the PDF or JPG.
Privacy and accuracy: Check that the full card, every printed detail and any QR code are visible before saving. InfoJano is a print-preparation utility only. It does not create official identity documents, change their details or replace the issuing authority.

Frequently Asked Questions

Where can I download my e-EPIC?

Use the Election Commission of India's official Voters' Services Portal. InfoJano does not issue or download voter IDs.

Does the Voter ID tool crop automatically?

The current Voter ID workflow is manual. Select the full card boundary for the front and back using the crop canvas.

Can I use a Voter ID PDF or image?

Yes. The studio accepts PDF, JPG and PNG files. Check the complete card preview before export.

Is this an official Election Commission website?

No. InfoJano is an independent utility and is not affiliated with the Election Commission of India.
