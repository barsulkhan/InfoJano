What percentage resizing means

Percentage resizing calculates new dimensions from the original image. At 50%, both width and height become half their original pixel values. At 100%, the dimensions remain the same. At 200%, both dimensions double. This is useful when you know how much to scale an image but do not have a required final pixel size.

How to resize by percentage

Open the InfoJano Image Resizer, upload a JPG, PNG or WebP file, and choose the By Percentage tab. Enter a value from 1 to 500. The tool calculates the corresponding width and height using the original image dimensions. Review the values, select JPG, PNG or WebP output and choose the quality setting before resizing.

Understand enlargement and reduction

A percentage below 100 reduces the pixel dimensions; a value above 100 enlarges them. Enlarging does not create new photographic detail, so a larger output may look softer than the original. Very large dimensions can also be demanding for a phone or browser. InfoJano limits each output dimension to 10,000 pixels and the total output to 40 megapixels for safer processing.

When percentage resizing is the right choice

Use percentage resizing when you want a consistent scale change for a photo, illustration or screenshot. If a form, website or print workflow specifies an exact width and height, use Custom Size or one of the available presets instead. If your goal is a smaller download measured in KB or MB, use the Image Compressor.

Frequently asked questions

What does resizing an image to 50% do?

It reduces both the original width and height to approximately half their pixel dimensions. The image area becomes about one quarter of the original pixel area.

Can I enlarge an image by 200%?

Yes. The current percentage mode accepts values up to 500%. Enlarging increases pixel dimensions but cannot restore detail that was not present in the original.

Does percentage resizing keep the image proportions?

Yes. Percentage mode calculates width and height from the same percentage of the original dimensions, so the original proportions are maintained.

Can I resize by percentage on a phone?

Yes. The tool is designed to work in a mobile browser. Very large source images or output dimensions may still depend on the memory and processing capacity of your device.
