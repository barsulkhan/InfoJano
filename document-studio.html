How to use Document to PDF & Image Studio

  1. Type in the editor or paste content copied from Microsoft Word.
  2. Use the toolbar to format headings, text, alignment, lists and tables.
  3. Choose page size, orientation and margins. Add another page when needed.
  4. Preview your pages, then export a selectable-text PDF or page images.

PDF note: PDF export opens your browser's print dialog. Choose “Save as PDF” to save a searchable, selectable-text document. JPG and PNG exports are rendered as page images.
