Repeated Percentage Change Calculator: Formula

Final value = Starting value × (1 + Percentage ÷ 100)ⁿ

Worked example

Increase 100 by 10% three times: 100 × 1.10³ = 133.10. The repeated increases compound because each step uses the latest value.

How to use this calculator

  1. Enter the starting value.
  2. Enter the percentage change per period. Use a negative percentage for a decrease.
  3. Enter the number of periods and calculate the final value.

Common questions

How do I calculate repeated percentage increase?

Multiply the starting value by (1 + rate/100) raised to the number of periods.

Is repeated percentage change the same as compound growth?

Yes, when each percentage is applied to the latest value, the calculation is compound growth or decline.

Do two 10% increases equal a 20% increase?

No. Two successive 10% increases multiply the starting value by 1.10 twice, giving a total increase of 21%.
