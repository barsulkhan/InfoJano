SUPPORT

Contact InfoJano

Use the public InfoJano GitHub issue tracker to report a broken tool, suggest an improvement or submit a correction.

Open InfoJano support on GitHub →

Privacy reminder: GitHub issues are public unless GitHub provides another private reporting route. Do not include passwords, account numbers, identity documents, private URLs or other sensitive personal information. For a privacy concern, describe the issue without publishing the personal data involved.

What to include in a bug report

  • The name and URL of the affected tool.
  • What you expected to happen and what happened instead.
  • Your browser and device type, if relevant.
  • A screenshot with personal or sensitive details removed.

InfoJano does not currently publish a verified support email address or postal address on this page. We will not invent one.
