Use the web image presets

The current Image Resizer includes Web Image Large at 1200 × 800 pixels, Web Image Medium at 800 × 600 pixels and Web Image Small at 400 × 300 pixels. These are general-purpose starting sizes for content images, cards and smaller placements. The correct size for a website depends on the actual display area and whether the site uses responsive image variants.

Match the image to its display area

Before resizing, check the width at which the image will appear and consider high-density screens. A 1200-pixel-wide source may be useful for a wider content area, while a smaller card may need fewer pixels. Avoid enlarging a small original unnecessarily, because extra pixels do not restore missing detail. If the website needs a different shape, use Custom Size and keep the aspect ratio on when possible.

Choose JPG, PNG or WebP

The tool offers JPG, PNG and WebP output, plus a quality control. Photos are often suitable for JPG or WebP, while graphics that need transparency may require PNG or a compatible WebP workflow. Always inspect the downloaded output and test it in the actual page design.

Resizing is not the same as compression

Changing dimensions can reduce the number of pixels, but the final file size also depends on image content, format and quality. The Image Resizer does not promise a target KB size. If your goal is to reduce an image to a particular file size or make a lighter upload, use the separate Image Compressor and check its resulting file size.

Frequently asked questions

What is the large website image preset?

The current Web Image Large preset is 1200 × 800 pixels.

What are the medium and small web presets?

Web Image Medium is 800 × 600 pixels and Web Image Small is 400 × 300 pixels.

Does resizing automatically optimize a website image?

It changes the pixel dimensions and lets you choose an output format and quality. It does not guarantee a target file size or automatically choose the ideal dimensions for every website layout.

Should I use Image Resizer or Image Compressor?

Use Image Resizer when you need different pixel dimensions. Use Image Compressor when reducing the image file size is your main goal.
