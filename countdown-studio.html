How Countdown Studio works

Does the countdown keep running when I close the page?

The target date is stored in the link. When you open it again, the remaining time is recalculated from the target date. Background notifications are not promised.

Does the YouTube or Facebook counter update automatically?

No. The goal counter in this first version is manual. A verified live counter would need official platform API access and may be limited by platform data rules.

Which time zone is used?

The default uses your device's local time. You can select India, Bangladesh, UTC, New York or London. Share the selected time zone with the link so other people see the same target moment.

Can I make a birthday or wedding surprise?

Yes. Choose the matching event type, add a name and a personal message, then share the countdown link. The celebration screen appears when the target time is reached.
