Set the exact width and height

Some websites, forms and design layouts ask for an image with a specific pixel width and height. In the InfoJano Image Resizer, upload a JPG, PNG or WebP image, choose Custom Size, and enter the required width and height in pixels. The tool accepts values from 1 to 10,000 pixels for each dimension, subject to a 40-megapixel output limit.

Keep the original proportions when needed

The aspect-ratio option is enabled by default. When it is on, changing the width recalculates the height from the original image proportions, and changing the height recalculates the width. This helps avoid stretching faces, objects or logos. If a destination specifically requires an exact rectangle and you understand the crop or distortion trade-off, you can turn the option off; the current tool resizes the full image into the entered dimensions rather than cropping it.

Choose an output format and quality

After setting dimensions, choose JPG, PNG or WebP. JPG is commonly suitable for photographs, PNG can preserve transparent areas when the source and browser output support them, and WebP can be useful for modern web workflows. The quality control ranges from 40% to 100%. Quality settings can affect output file size and appearance; resizing does not guarantee a particular KB limit.

A practical pixel-sizing example

If a form requests 600 × 600 pixels, enter 600 for width and 600 for height. If your original photo is not square and you keep the aspect ratio locked, the other dimension will change to preserve its shape. If the form requires both values exactly, compare the result with the form's instructions before submitting.

Frequently asked questions

How do I resize an image to exact pixels?

Upload a supported image, select Custom Size, enter the required width and height in pixels, choose an output format and quality, then select Resize Image and download the result.

Does the tool keep the original aspect ratio?

Yes. Keep original aspect ratio is enabled by default. It adjusts the other dimension when you change width or height. Turn it off only when you intentionally need independent dimensions.

Can I enter centimetres or DPI?

No. The current Image Resizer accepts pixel dimensions. It does not provide editable centimetre, millimetre or DPI fields.

Are my images uploaded to a server?

The current resizing process runs in your browser. The image is processed locally rather than uploaded to InfoJano.
