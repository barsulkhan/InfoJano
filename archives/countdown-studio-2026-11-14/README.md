## Features present in the preserved source

1. Event countdown creation with event presets: Event, Birthday, Wedding, Holiday, Exam, Launch, Valentine, New Year and Graduation.
2. Event name, target date and time, custom message at zero, and celebration theme selection.
3. Celebration themes: Birthday confetti, Fireworks, Romantic hearts, Golden celebration, Ocean blue, Neon party and Pastel dream.
4. Optional photo and video URLs, plus multi-file photo/video upload from the device.
5. Time-zone choices: device local time, UTC, India (Asia/Kolkata), Bangladesh (Asia/Dhaka), New York and London.
6. Live preview with days, hours, minutes and seconds.
7. Create/start countdown, copy share link and save on this device.
8. Celebration overlay and confetti effect when the target time arrives.
9. YouTube subscriber goal tracker: channel URL/@handle, API key, connect and refresh controls, live subscriber count and progress display.
10. Goal label and subscriber target, shareable goal link and downloadable progress card.
11. Responsive layout, reduced-motion support, SEO metadata, Open Graph metadata and PWA manifest.
