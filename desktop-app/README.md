# InfoJano Windows Desktop App

This is the Windows desktop wrapper for the hosted InfoJano tools portal.

- Loads the live site at https://barsulkhan.github.io/InfoJano/
- Requires an internet connection.
- Build artifacts are generated by GitHub Actions on a Windows runner.
- Setup installer: `InfoJano-Setup-1.0.0.exe`
- Portable app: `InfoJano-Portable-1.0.0.exe`

The downloads must not be linked on the website until the Windows build workflow completes successfully and the release assets are verified.
