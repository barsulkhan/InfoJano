Read and Edit an Existing QR Code / Barcode

Upload a clear image of an existing QR code or supported barcode. We’ll try to read its contents and place the text or link in the box above so you can edit it and generate a new QR code.

After the code is read, edit its contents in the Text or Website URL box above, then tap Generate QR Code.

Note: the new output is a QR code, even if the uploaded image is a traditional barcode. Some blurry, damaged or unsupported barcode images may not be readable.

An internet connection is required to generate the QR code. Do not enter passwords or sensitive personal information.

What Is a QR Code?

A QR code is a two-dimensional code that a phone camera can scan to open a link or read stored information.

How to Use This QR Maker

Enter a website link or text and tap Generate QR Code. Scan the resulting image with a phone camera to test it.

QR Code Example and Print Checks

You can use a QR code to share a website address or text supported by the generator. After creating it, scan it with a phone camera to confirm it opens the intended content.

Before publishing or printing

  • Check the encoded URL carefully and use a trusted destination.
  • Keep enough contrast between the QR code and its background.
  • Test the printed size and scan it from the expected distance.
