    PERCENT CHANGE GUIDE

    How to Calculate Percentage Change

    Percentage change tells you how much a value has increased or decreased compared with its starting value. Enter the original value as Old value and the updated value as New value. The order matters because the old value is the baseline for the calculation.

    Percentage change formula

    Percentage change = ((New value − Old value) ÷ |Old value|) × 100

    The absolute value bars around the old value mean the denominator is treated as positive. A positive result means an increase, a negative result means a decrease, and zero means no change.

    Worked examples

    Percentage increase

    Old value: 80 · New value: 100

    (100 − 80) ÷ 80 × 100 = 25% increase

    Percentage decrease

    Old value: 100 · New value: 80

    (80 − 100) ÷ 100 × 100 = 20% decrease

    Large increase

    Old value: 58 · New value: 10,080

    (10,080 − 58) ÷ 58 × 100 = 17,279.31% increase

    How to calculate percentage change in Excel or Google Sheets

    If cell A2 contains the old value and cell B2 contains the new value, use this formula:

    =(B2-A2)/ABS(A2)

    Format the result cell as Percentage. If A2 is zero, the formula cannot return a defined percentage change because it would divide by zero.

    Percentage change vs. percentage difference

    Percentage change compares a new value with a specific starting value, so the order of the values matters. Percentage difference compares two values symmetrically, usually using their average as the reference. They answer different questions and should not be used interchangeably.

    Reverse percentage formula

    Use reverse percentage when you know the final value and the rate that was applied, and want to recover the starting value. For an increase, divide the final value by 1 + (rate ÷ 100). For a decrease, divide it by 1 − (rate ÷ 100).

    Original value after an increase = Final value ÷ (1 + rate ÷ 100)

    Original value after a decrease = Final value ÷ (1 − rate ÷ 100)

    Example: if a value becomes 120 after a 20% increase, the original value is 120 ÷ 1.20 = 100. If a value becomes 80 after a 20% decrease, the original value is 80 ÷ 0.80 = 100.

    Percentage difference formula

    Use percentage difference when neither value is the starting point. The calculator divides the absolute difference by the average of the two absolute values, then multiplies by 100.

    Percentage difference = (|A − B| ÷ ((|A| + |B|) ÷ 2)) × 100

    For 80 and 100, the difference is 20 and the average magnitude is 90, so the percentage difference is 20 ÷ 90 × 100 = 22.22%. This differs from the 25% percentage change from 80 to 100 because percentage change uses 80 as its starting-value baseline.

    COMMON QUESTIONS

    Percentage Change Calculator FAQs

    How do I calculate percentage change between two numbers?

    Subtract the old value from the new value, divide the result by the absolute old value, and multiply by 100. This calculator performs those steps and labels the result as an increase, decrease, or no change.

    What is the difference between percentage change and percentage increase?

    Percentage change can be positive or negative. A positive result is a percentage increase; a negative result is a percentage decrease. The formula is the same, but the direction depends on whether the new value is higher or lower than the old value.

    How does reverse percentage work?

    Divide the final value by 1 plus the rate as a decimal for an increase, or by 1 minus the rate as a decimal for a decrease. For example, 120 after a 20% increase means the original value was 120 ÷ 1.20 = 100.

    What is percentage difference?

    Percentage difference compares two values when neither is treated as the original or starting value. It divides the absolute difference by the average of the two absolute values, then multiplies by 100. Switching the order of the values does not change the result.

    What is the difference between percentage difference and percentage change?

    Percentage change uses a specific starting value as its baseline, so order matters. Percentage difference treats both values equally and uses their average magnitude as the reference, so order does not matter.

    Can I calculate percentage change if the old value is zero?

    No defined percentage change can be calculated from an old value of zero using this formula because it requires division by the old value. The calculator displays an explanation instead of showing an invalid number.

    Can percentage change be negative?

    Yes. A negative percentage change means the new value is lower than the old value. For example, a change from 100 to 80 is a 20% decrease, or −20% when shown as a signed percentage.

    How do I calculate percentage change in Excel?

    Put the old value in A2 and the new value in B2, then enter =(B2-A2)/ABS(A2) in another cell. Format that cell as Percentage. The old value must not be zero.

    Can I calculate several percentage changes at once?

    Yes. Use Batch Percentage Change and enter one pair of values per line, with the old value first and the new value second. You can calculate up to 100 rows at a time and export valid results as a CSV file.

    Are my calculations saved?
