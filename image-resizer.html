How to Resize an Image

Select an image, enter the desired width and height in pixels, choose an output format, and tap Resize Image.

Keeping the aspect ratio helps prevent the image from looking stretched. JPG is suitable for photographs, while PNG can preserve transparency.

Image Resizing Example

If a website asks for a 600 × 600 pixel image, use those exact dimensions when the tool supports them. If the original photo has a different shape, decide whether to preserve proportions or crop it to fit.

Before exporting

  • Check the required pixel dimensions and file format.
  • Preserve the aspect ratio when stretching would distort the subject.
  • For print, follow the destination’s physical-size and DPI requirements too.

Image Resizer FAQs

How do I resize an image?

Choose an image, enter the required dimensions, and create the resized copy.

Will changing dimensions stretch the image?

If width and height do not match the original aspect ratio, the image may stretch unless aspect ratio is preserved.

What dimensions should I use?

Use the pixel dimensions required by the website, form, or printer. Check its current instructions first.
