Available print and document presets

The current tool includes A4 Print at 2480 × 3508 pixels, A5 Print at 1748 × 2480 pixels and A6 Print at 1240 × 1748 pixels. It also includes a Document Image preset at 1024 × 1448 pixels. These presets provide fixed pixel dimensions for common page proportions and document-style images.

Choose the page size you need

Select the A4, A5 or A6 preset that matches your intended page. The tool places the preset's width and height into the resize controls. A4 is the largest of these three page formats, A5 is half an A4 sheet by area, and A6 is smaller again. Confirm that the destination requires the same page orientation and dimensions before downloading.

Pixel dimensions are not the whole print specification

The final physical print size also depends on print resolution, document layout and printer settings. The current Image Resizer sets pixel width and height; it does not expose an editable DPI field or guarantee a physical print size. If an office, school, form or print shop specifies a DPI or physical measurement, verify that requirement separately.

Choose a suitable output format

JPG is commonly used for photographs, while PNG may be preferable for graphics with sharp text or transparency. The tool also offers WebP output. After resizing, download and inspect the image. For a multi-page document or a PDF workflow, use InfoJano's Image to PDF tool rather than treating a resized image as a complete print-ready PDF.

Frequently asked questions

What is the A4 pixel preset?

The current A4 Print preset is 2480 × 3508 pixels.

What are the A5 and A6 pixel presets?

A5 is 1748 × 2480 pixels and A6 is 1240 × 1748 pixels in the current tool.

Does the Image Resizer set 300 DPI?

The current tool does not provide an editable DPI setting. It sets pixel dimensions only, so check print resolution and physical size in your document or print workflow.

Can I create a PDF from the resized image?

The Image Resizer downloads an image file. Use the separate Image to PDF tool if you need to place images into a PDF.
