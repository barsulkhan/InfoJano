InfoJano ID Card Print Studio

Prepare ID cards for printing • PDF or photos • A4 or 4×6

1Choose card type

PDF pages and photos are supported. You can upload two separate photos, or one PDF/scan containing the front and back. Files are processed in this browser; they are not intentionally uploaded to an InfoJano server.

Choose a PDF or one or more photos to begin.

2Assign front and back

The app lists uploaded images and PDF pages. Choose the correct front and back yourself if automatic identification is uncertain.

Manual card crop (recommended for Aadhaar PDF)

Aadhaar PDF: choose the PDF page in the Front source list and drag around ONLY the front PVC-card rectangle. Press “Use crop as Front”. Then choose the same PDF page in the Back source list; the crop view will switch to that source. Drag around ONLY the back PVC-card rectangle (including the full QR code) and press “Use crop as Back”. Do not select the whole page or both cards together.

Select a source above to crop it.

3Card size and print layout

Processing order: crop the card, resize it to the selected physical dimensions at the chosen DPI, then draw a thin cut line on the exact outer edge of that fixed-size box. The line does not add to or subtract from the selected card dimensions. Check both previews and print at Actual size / 100%.

Print layout preview will appear here.

4Download print-ready PDF

Print at “Actual size” / 100% scale. Turn off “Fit to page” if exact physical dimensions are important. This first version uses a manual front/back selection to avoid silently printing the wrong side.
