# Elapsed Time Calculator — SEO Keyword & Landing-Page Research

**Research date:** 2026-11-15  
**Target page:** https://infojano.com/time-calculator.html  
**Research status:** Preliminary / metrics-gated. Search-intent and SERP competitor review completed; country-level volume, KD and CPC metrics are unavailable in the connected Ahrefs entitlement during this run. Do not treat suggested terms as validated volume winners.

## 1. Decision

**Decision: REVISE — optimize the existing calculator page first; do not create a second generic elapsed-time SEO page yet.**

The current `/time-calculator.html` is already a dedicated, canonical calculator landing page. The core intent clusters (elapsed time, time difference, time duration, add/subtract time) are closely related and can be served by its existing modes. A second page targeting the same generic intent risks competing with the existing URL (keyword cannibalization) without proven distinct search demand.

Create a separate page only if subsequent country-specific keyword/SERP research demonstrates a genuinely distinct task and content experience, for example:
- work hours / shift calculator with unpaid breaks and decimal payroll hours;
- date duration calculator for multi-day date-time spans;
- time zone difference calculator (not currently the same user job).

These would need unique functionality and useful content, not doorway pages or near-duplicate copy.
