Available photo presets in InfoJano

The current Image Resizer includes a Passport Photo preset of 413 × 531 pixels and a separate 3.5 × 4.5 cm ID Photo preset that is also represented as 413 × 531 pixels at 300 DPI. It also includes a 2.9 × 3.6 cm Passport preset represented as 342 × 425 pixels at 300 DPI. These are preset labels and pixel values in the tool; they are not a guarantee that every passport office, visa service, exam board or government form accepts those dimensions.

Check the receiving authority's photo rules

Photo requirements can differ by country, application type and issuing authority. They may specify physical size, pixel dimensions, file size, background, face position, lighting and recency. Before resizing, read the current instructions for the exact application. If the required pixel dimensions differ from the presets, use Custom Size and enter the requested width and height.

Resize without stretching the face

Upload your photo and select the relevant preset. The preset fills the width and height fields with its listed dimensions. Preset selection turns off the aspect-ratio lock because the output is set to those exact dimensions. Check the preview and ensure that the face is not stretched. The tool does not crop, reposition or automatically validate a passport photograph.

Understand DPI and physical photo size

The preset descriptions include 300 DPI labels for the two centimetre-based options, but the current tool does not offer a user-editable DPI field or a physical-size print dialog. Pixel dimensions alone do not guarantee the final printed size. Check the file and print settings required by the authority before submitting or printing.

Frequently asked questions

What passport photo sizes are available?

The current tool lists a Passport Photo preset at 413 × 531 pixels and a 2.9 × 3.6 cm Passport preset at 342 × 425 pixels with a 300 DPI label. Requirements vary, so verify the exact application instructions.

Does InfoJano guarantee that my photo will be accepted?

No. The tool resizes pixel dimensions only. It does not check official photo rules, facial position, background, expression, file-size limits or application eligibility.

Can I change DPI or centimetres directly?

No. The current tool does not include editable DPI, centimetre or millimetre fields. It offers the listed pixel presets and custom pixel dimensions.

Will the preset crop my photo?

No automatic crop or face-positioning tool is present. The preset sets exact output dimensions, so check the result carefully to avoid unwanted stretching.
